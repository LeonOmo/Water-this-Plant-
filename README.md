# Water this Plant

A rather simple Project to monitor soil mostore lvls for my plant. It provied led feedback and it send a message to your phone to alert me when it needs water.

## Components 

- Microcontroller: Esp32
- Sensor: Capacitive Soil Moisture Sensor
- LEDs: 1x Green LED & 1x Red LED
- Resistors: 2x 220 Ohm Resistors
- Connecting everything: PCB/Breadboard
